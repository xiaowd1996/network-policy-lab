# 如何验证，以及不能证明什么

## 可安全复核的入口

```console
python scripts/validate.py
python -m unittest discover -s tests -v
python demo/policy_demo.py
```

依赖安装需要访问包源；安装完成后，上面三个检查不需要代理服务器或任何凭据。
CI 使用同样入口，在隔离的 GitHub 托管环境执行，不连接生产主机。

## 测试范围

| 层级 | 本仓库提供的证据 | 不足以证明 |
|---|---|---|
| 静态检查 | Python/JSON/YAML 解析，文件类型与通用敏感模式扫描，531 条规则基线 | 无任何泄露、引擎全版本兼容 |
| 规则变换单测 | 新增范围、原顺序、非目标字段、幂等、缺少安全前提时拒绝 | 真实进程识别、完整路由语义或实际联网 |
| 离线演示 | 调用实际维护函数，在内存中展示不变量 | 上传下载、服务端在线状态或出口地理位置 |
| 历史参考 | 2026-10-19 的迁移材料、代码和配置结构 | 当前生产状态、持续稳定性或设备验收 |

## 已知边界

本次本地验收执行了 14 项单元测试；结果应以实际命令输出及对应提交的 CI 为准，不作为生产稳定性指标。
微信规则函数在公开副本中的缩进兼容修复有回归测试，但未部署到生产环境。

- 样例节点是假地址/占位凭据，不能直接联网。静态检查不是 sing-box/Mihomo 的在线配置验收。
- `reference/` 不作为本仓库测试时的部署入口，部分脚本有系统写操作，切勿在生产环境直接运行。
- 公开仓库无原始审计数据和生产快照，所以不展示吞吐、延迟、月流量或可用率结论。
- 当前测试不是对所有迁移、监控或并发租约行为的完整覆盖；新增这些测试属于后续工作。
- CI 徽章仅表示某次代码检查的结果，不代表生产服务健康。
- 本机 Drive 额外代理的真实账号上传/下载仍需设备实测，不作为本项目已经完成的成果。

## 发布前人工复核

再次比对本地私有来源的地址/凭据集合；审查可达提交历史及文件类型，排除备份、日志、数据库、密钥和可用链接。
该私有来源集合不会上传到 GitHub，也不会在公开 CI 中回显。
自动扫描与人工检查都不能保证未来新增内容天然安全；每次发布仍需复核。
