# 安全维护与恢复

## 修改前

确认当前主机、现有密钥、配置路径与部署代际，不能凭历史脚本默认地址执行。
只读核对主代理、Nginx、审计服务、监听、四份独立订阅、磁盘内存与网卡状态。
未知订阅路径应为 404；健康检查不要消费一次性链接。
不向日志输出真实节点、订阅路径、密码、用户名称或令牌。

## 修改订阅

1. root 私有目录中保留原字节、权限、所有者、校验值及时间。
2. 默认 dry-run，先产生候选文件，不覆盖正在服务的文件。
3. YAML 解析、规则优先级与节点检查，确认非目标字段不变。
4. 同文件系统临时文件写入并 fsync，保留权限后原子替换。
5. 对授权链接做受控 HTTPS 回读，在内存中比较，禁止打印 URL 与响应配置。
6. 比对主配置、证书、长期凭据和服务状态；失败时从明确备份回退。

只改单纯静态订阅不需要重启 sing-box。服务配置变更必须先做适配版本的配置检查。
Nginx 变更先 `nginx -t`，再只重载所需服务；不要把它扩大为整机重启。

## 迁移

`reference/migration/` 是历史流程的脱敏参考，含有安装、账号/权限、服务启动等写操作。
不能当作当前机器可直接运行的安装器。必须人工适配源/目标、依赖、版本、UID/GID、证书路径和防火墙。
保留旧机作为回退；客户端订阅主机、节点地址及证书名称必须协调切换。
历史数据库与新机当前计数分开保存，不能拼成连续精确统计。

## 恢复边界

仓库不含生产密钥、令牌、证书、真实配置或数据库，不能单独恢复原有身份。
真正恢复需要独立、加密或严格访问控制的私有备份，以及离机保管的密钥和账户恢复资料。
本次没有重新从新机获取完整快照，也没有修改或重启任何生产服务。

## 验收用语

分别记录：静态候选检查、在线服务加载、客户端已更新、实际设备功能测试。
进程存在、端口开放、节点测速成功和短时 HTTP 200 都不能代替完整业务验收。
对 WebSocket/HTTP 回退问题应同时看客户端错误、代理链路及服务器元数据，而非直接归因给站点。
